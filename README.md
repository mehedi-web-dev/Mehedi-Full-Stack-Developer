# 💻 Mehedi.dev — Full-Stack Developer Portfolio

A modern developer portfolio website showcasing my skills, technologies, services, and experience in WordPress and Full-Stack Web Development.

---

## 📊 Project Overview

Mehedi.dev is a personal developer portfolio designed to present my professional background, technical skills, development services, and contact information in a clean and modern interface.

The portfolio highlights my journey from WordPress development toward Full-Stack Web Development and showcases the technologies and services I work with.

## 📱 Responsive Design

Responsive design has **not been implemented** in this project.

The current version is primarily designed for desktop screen sizes.

---

## 📦 Dependencies

No JavaScript framework or backend dependency is used.

The project is built using only HTML5 and CSS3.

---

## 💻 How to Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. You can also use the Live Server extension.
5. No additional setup is required.
